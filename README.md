A modern, production-ready **frontend landing page revamp** inspired by  
https://www.lighthouse.storage, built to improve clarity, UX, and visual presentation for a Web3 storage product.

👉 **Live Demo:** https://lighthouse-revamp.vercel.app

## Overview

This repository contains a **frontend landing page implementation** for Lighthouse Storage, focused on presenting a complex decentralized storage product in a clean, accessible, and conversion-friendly way.

The work involved:
- Designing and structuring a full marketing website
- Implementing responsive, reusable UI components
- Improving information hierarchy for Web3 and non-Web3 users
- Shipping a production-grade frontend deployed on Vercel

This work was delivered as a **paid frontend engagement** and is showcased here as part of my professional portfolio.

---

## Scope of Work

- End-to-end frontend development
- UI/UX implementation from concept to deployment
- Component-driven architecture
- Performance-friendly animations
- Mobile-first responsiveness

```bash
cd lighthouse-revamp
npm install
npm run dev
```

`http://localhost:3000`
